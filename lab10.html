VLANs Separate Broadcast Domains

A VLAN creates a logical broadcast domain on a switch. Hosts in different VLANs generally require a Layer 3 device to communicate. A switch access port belongs to one data VLAN. VLAN 1 is the default VLAN on Cisco switches.

Switch(config)# vlan 30
Switch(config-vlan)# name ENGINEERING
Switch(config)# interface fastethernet0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 30

VTP can distribute VLAN information between participating switches; its mode and behavior depend on the configured network.

802.1Q Interswitch Trunks

A trunk can transport traffic from multiple VLANs over one physical link. IEEE 802.1Q inserts a VLAN tag into frames on the trunk, except that frames in the native VLAN are normally sent untagged. The default native VLAN is VLAN 1.

Switch(config)# interface gigabitethernet0/1
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk native vlan 99
Switch# show interfaces trunk

Configure matching native VLANs on both ends of the trunk and follow the assigned activity's VLAN plan.

Link Aggregation with EtherChannel

EtherChannel bundles compatible physical links into a logical port-channel. The textbook covers three approaches: static on, Cisco PAgP (desirable/auto), and standards-based LACP (active/passive). Both sides must use compatible settings.

Switch(config)# interface range gigabitethernet0/1 - 2
Switch(config-if-range)# channel-group 1 mode active
Switch# show etherchannel summary

Member links must agree on important parameters such as speed, duplex, and VLAN/trunk settings.
