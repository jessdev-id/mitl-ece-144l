Lecture & Discussion Notes

Learn the controls introduced in Chapter 3 before applying them in Packet Tracer.

Logical and Physical views

Logical view displays network devices and connections. Physical view organizes equipment by location. In Lab 3.1, navigate Home City → Corporate Office → Main Wiring Closet to examine equipment, then use Inspect Front to examine the router. Return to Logical view to observe device status.

Power Cycle Devices restarts the simulated equipment; Fast Forward Time advances the simulation clock, helping you observe link status changes.

Preferences for efficient work

Open Options → Preferences on Windows, or Cisco Packet Tracer → Preferences on macOS. Under Interface, enable Always Show Port Labels in Logical Workspace and clear Show Link Lights. Under Font, set the CLI font size to 20 points, Router IOS Text to White, and Router IOS Background to Black. Under Miscellaneous, set automatic backup to 10 minutes.

Server services and wireless devices

Lab 3.2 adds Server0 above Switch0 and connects Server0 FastEthernet0 to Switch0 FastEthernet0/3 using Copper Straight-Through. The server's Services tab exposes options including DHCP. The lab also adds a WRT300N wireless router and examines its GUI settings.

This chapter explores configuration options; it does not require complete IP reachability for newly added devices.

Replacing a laptop network module

On Laptop0, open the Physical tab, power the device off, remove the PT-LAPTOP-NM-1CFE Ethernet module, insert the WPC300N wireless interface, and power the laptop back on. Powering off first is essential when replacing a module.
