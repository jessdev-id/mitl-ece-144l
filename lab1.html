Lecture & Discussion Notes

Review core theory, architectural layer functions, and protocol interactions.

What is a Networking Model?

A networking model (or architectural blueprint) is a comprehensive set of documents defining standards and rules (protocols). Together, they define everything required for hardware and software components from different vendors to communicate seamlessly.

Architectural Blueprint Analogy:

Just as standard building blueprints allow electricians, plumbers, and carpenters to build a house without interference, networking models allow vendors (Cisco, Apple, Intel) to build compatible hardware.

Historical Progression & Network Scales

  • 1970s Vendor-Proprietary Era: Models like IBM SNA locked companies into single-vendor hardware ecosystems.
  • 1980s Standardization Push: ISO developed the 7-layer OSI Model, while US DoD researchers finalized TCP/IP.
  • 2000s+ TCP/IP Dominance: TCP/IP became universal. OSI standards faded, but OSI terminology remains essential.
SOHO vs. Enterprise: SOHO networks combine router, switch, and AP into one box; enterprise networks use dedicated multi-tiered hardware switches, routers, and firewalls.

Comparing OSI (7-Layer) and Updated TCP/IP (5-Layer) Models

OSI Layer # OSI Layer Name TCP/IP 5-Layer Name OSI PDU Name Primary Functions & Protocols
Layer 7 Application Application (Layer 5-7) Data (L7PDU) Network services to apps (HTTP, HTTPS, POP3, SMTP, DNS)
Layer 6 Presentation Data (L6PDU) Data formatting, encryption, SSL/TLS, compression
Layer 5 Session Data (L5PDU) Initiating, maintaining, terminating conversations
Layer 4 Transport Transport Segment (L4PDU) End-to-end data delivery, error recovery, flow control (TCP, UDP)
Layer 3 Network Network / Internet Packet (L3PDU) Logical addressing & routing across networks (IPv4, IPv6, ICMP)
Layer 2 Data Link Data Link Frame (L2PDU) Hop-to-hop framing, MAC addressing (Ethernet 802.3, Wi-Fi 802.11, PPP)
Layer 1 Physical Physical Bits (L1PDU) Transmitting electrical, optical, or RF signals (UTP, Fiber)
HTTP Mechanics

Web browsers use HTTP GET requests to fetch web pages from servers, receiving HTTP 200 OK headers with payload.

1. GET /home.htm (Client)

2. HTTP/1.1 200 OK (Server)

3. [HTML Payload Data]

TCP Error Recovery

Guarantees reliable delivery using Sequence Numbers (SEQ) and Acknowledgments (ACK).

Error Recovery Example:

If Segment 2 drops, the receiver detects missing SEQ and requests re-transmission via ACK 2.

Layer Interactions

Explains how protocol layers talk on single vs separate network nodes.

Adjacent-Layer: Same computer (HTTP asks TCP for reliable delivery).

Same-Layer: Different computers (TCP on Host A communicates with TCP on Host B).

IP Addressing & Routing

Dotted-decimal IP addressing (e.g. 10.1.1.10) provides global network logical locations. Hosts send remote destination packets to their Default Gateway router, which inspects routing tables to forward hop-by-hop.

ARP (Address Resolution)

Dynamically maps Layer 3 IP addresses to Layer 2 MAC addresses on local LAN links using ARP Request broadcasts and ARP Reply unicasts before encapsulation can occur.

DNS & ICMP Utilities

DNS: Translates human domain names (e.g. mapua.edu.ph) into IP addresses.
ICMP: Protocol behind ping for verifying Layer 3 IP reachability.

Lab 1.1 Complete Cisco Packet Tracer Build Guide

Topology Specifications, Addressing Tables & CLI Commands

  • 1x Router: Cisco 4331 or 2911 ISR (Router-R1)

  • 1x PC: End-User Computer Host (Bob-PC)

  • Bob-PC (Fa0) → SW1 (Fa0/1) [Copper Straight-Through]

3. Step-by-Step Cisco IOS CLI Commands for Router R1

Click into Router R1 > CLI tab and paste the following commands:

// Enter privileged exec and global configuration mode

enable

configure terminal

hostname R1


// Configure LAN 1 Interface (Connecting to SW1 & Bob-PC)

interface GigabitEthernet0/0/0

ip address 10.1.1.1 255.255.255.0

no shutdown

exit


// Configure LAN 2 Interface (Connecting to Larry-Server)

interface GigabitEthernet0/0/1

ip address 10.2.2.1 255.255.255.0

no shutdown

exit


// Save configuration to NVRAM

end

copy running-config startup-config

4. Simulation & Packet Inspection Steps

  1. Open Larry-Server > Services > HTTP and verify HTTP service is turned ON.
  2. Open Bob-PC > Desktop > Command Prompt, type ping 10.2.2.20 to verify ICMP end-to-end reachability.
  3. Switch Packet Tracer to Simulation Mode (Shift + S). Edit Filters to show only HTTP, TCP, and ICMP.
  4. Open Bob-PC Web Browser and enter http://10.2.2.20.
  5. Click Capture / Forward to advance packet envelopes hop-by-hop. Click on the envelope icons at R1 to inspect In Layers and Out Layers headers!
