Lecture & Discussion Notes

128-Bit IPv6 Addressing

IPv6 addresses contain 128 bits written as eight hexadecimal hextets. Omit leading zeros in a hextet, and use :: once to replace one or more consecutive all-zero hextets. 

2001:0000:0011:0001:0000:0000:0001:1AB1
2001:0:11:1::1:1AB1

The textbook frequently uses a /64 prefix: 64 bits for the network and 64 bits for the interface identifier.

Recognizing IPv6 Address Types

Type Prefix / Example Purpose
Global unicast 2001:DB8::/32 (documentation example) Globally scoped unicast
Unique local FC00::/7 Private-use addressing
Link-local FE80::/10 Local-link communication
Multicast FF00::/8 Group delivery; FF02::1 reaches all nodes on a link
Anycast Shared unicast address Route to a nearby member of a group

IPv6 uses multicast rather than IPv4-style broadcast.

Configure and Verify IPv6 on IOS

On an interface, use ipv6 address with the prefix length and enable the port with no shutdown . Enable router IPv6 forwarding with ipv6 unicast-routing when routing between interfaces is required. 

R1(config)# ipv6 unicast-routing
R1(config)# interface fastethernet0/0
R1(config-if)# ipv6 address 2001:AAAA:BBBB::1/64
R1(config-if)# no shutdown
R1# show ipv6 interface brief
R1# show ipv6 interface fastethernet0/0

The interface identifier varies by hardware and device model; always check the actual interface name in the assigned Packet Tracer file.

Modified EUI-64 and SLAAC

Modified EUI-64 derives a 64-bit interface identifier from a 48-bit MAC address by inserting FFFE and inverting the universal/local bit. SLAAC uses IPv6 Router Advertisements to allow hosts to configure an address automatically. Neighbor Discovery uses ICMPv6, including link-local addresses. 

R1(config-if)# ipv6 address 2001:DB8:1:1::/64 eui-64
R1(config-if)# ipv6 address autoconfig

SLAAC and DHCPv6 can be used in different combinations depending on network requirements.

Verify IPv6 Parameters on a Client

Windows uses ipconfig /all to display IPv6 addresses, temporary addresses, link-local addresses, and gateway information. The textbook references ifconfig for macOS and Linux; current Linux installations may use ip -6 addr .

In Packet Tracer, open a PC, inspect Desktop → IP Configuration , and use the command prompt to verify reachability. 

PC> ipconfig
PC> ping 2001:DB8:1:1::1
