Who Is Connected to This Device?

Layer 2 discovery protocols let a device advertise information about itself to directly connected neighbors. Network administrators use these advertisements to identify device names, local and remote interfaces, and adjacent equipment without already knowing the entire topology.

CDP and LLDP are neighbor-discovery protocols , not IP routing protocols. A router does not forward CDP messages to devices beyond the directly connected link.

CDP — Cisco Proprietary

CDP is enabled by default on Cisco routers and switches. It operates at Layer 2 without relying on TCP, UDP, or ICMP. Cisco IP phones can use CDP to exchange capability and VLAN-related information with switches. 

Switch# configure terminal
Switch(config)# cdp run
Switch(config)# interface gigabitethernet0/1
Switch(config-if)# cdp enable
Switch(config-if)# end
Switch# show cdp neighbors detail

To disable CDP globally, use no cdp run . To disable it on one interface, use no cdp enable . Limit discovery advertisements on interfaces where they would reveal information unnecessarily.

LLDP — Open Standard

LLDP performs similar neighbor discovery across equipment from different vendors. The chapter explains that LLDP is not globally enabled by default on Cisco IOS. Use lldp run to enable it, then lldp transmit and lldp receive for interface-level behavior. 

Switch# configure terminal
Switch(config)# lldp run
Switch(config)# interface gigabitethernet0/1
Switch(config-if)# lldp transmit
Switch(config-if)# lldp receive
Switch(config-if)# end
Switch# show lldp neighbors detail

LLDP is used on Ethernet interfaces. CDP can be used for discovery on supported non-Ethernet interfaces.

Key Differences & Verification

Feature CDP LLDP
Origin Cisco proprietary Open standard
IOS global default Enabled Not enabled
Enable globally cdp run lldp run
Interface commands cdp enable lldp transmit / receive
Show neighbors show cdp neighbors detail show lldp neighbors detail

Use show cdp / show lldp for global status, and show cdp interface / show lldp interface for interface status.
