Cisco IOS and Command Modes

Cisco Internetwork Operating System (IOS) provides a command-line interface through console or SSH access. User EXEC permits basic inspection; privileged EXEC gives access to advanced verification and configuration modes.

Mode Prompt Entry
User EXEC Router> Initial CLI
Privileged EXEC Router# enable
Global configuration Router(config)# configure terminal
Interface configuration Router(config-if)# interface gigabitethernet0/0
Console line Router(config-line)# line console 0

Passwords, Help, and History

enable secret protects privileged EXEC mode. Under line console 0 , use password and login to require a console password. Use ? for help, conf? for matching command names, and Tab for completion.

Up arrow / Ctrl+P recalls earlier commands; Down arrow / Ctrl+N advances; Left arrow / Ctrl+B and Right arrow / Ctrl+F move the cursor.

Verify Before and After Changes

show ip interface brief summarizes interface IP addresses and status. show running-config displays the active configuration. debug can display activity as it occurs; use undebug all to disable debugging. Debugging can affect device performance, so use it carefully. 

R1# show ip interface brief
R1# show running-config
R1# undebug all

Running and Startup Configurations

running-config is the active configuration in RAM. startup-config is stored in NVRAM and used at boot. Save with copy running-config startup-config ; inspect with show startup-config . The textbook also introduces erase startup-config ; do not execute it on a lab you need to retain.
