Redundancy Without Switching Loops

Physical redundancy improves availability but can create Layer 2 loops. STP chooses a loop-free logical topology by selecting a root bridge and putting some redundant ports into non-forwarding states.

In classic PVST+, each VLAN has its own spanning-tree instance. Root bridge ports are designated and forwarding. Every nonroot switch selects a lowest-cost root port; redundant non-designated ports block.

Bridge ID and Root Cost

Switches exchange bridge protocol data units (BPDUs) to elect the lowest bridge ID. The bridge ID includes a priority/system-ID component and the MAC address. The default configurable priority is 32768; a lower priority can make a switch the root bridge. 

DISTSW1# configure terminal
DISTSW1(config)# spanning-tree vlan 1 priority 4096
DISTSW1(config)# end
DISTSW1# show spanning-tree

For VLAN 1, the example displays effective priority 4097 because of the VLAN system-ID extension. Verify the root by finding “This bridge is the root.”

Rapid PVST+ Convergence

Rapid PVST+ uses rapid spanning-tree behavior per VLAN. It supports faster convergence through proposal/agreement exchanges and adds alternate and backup port roles. The chapter describes blocking, learning, forwarding, and disabled states. 

DISTSW1# configure terminal
DISTSW1(config)# spanning-tree mode rapid-pvst
DISTSW1(config)# end
DISTSW1# show spanning-tree

In the chapter's output, protocol ieee indicates classic PVST+ and protocol rstp indicates Rapid PVST+.

Optional STP Features

PortFast: Allows host-facing access ports to transition quickly; do not use on interswitch links.

Root Guard: Blocks a designated port receiving superior BPDUs by placing it in root-inconsistent state.

Loop Guard: Prevents a non-designated port from incorrectly forwarding when expected BPDUs stop arriving.

BPDU Filter: Controls BPDU exchange; improper use can create loops.

BPDU Guard: Disables a protected edge port when a BPDU arrives. 

ACCSW1(config)# interface gi0/3
ACCSW1(config-if)# spanning-tree portfast
