Lecture & Discussion Notes

Explore the concepts before starting the guided laboratory.

Building the first network

Chapter 2 constructs a network consisting of one Cisco 2911 router, two 2950-24 switches, and two PCs. The arrangement is PC0 — Switch0 — Router0 — Switch1 — PC1. Devices are placed from the lower-left device palette and linked using the Connections tool (automatic cable selection).

Router interfaces may initially show red link indicators because they are administratively shut down. The no shutdown command enables each interface.

Two separate /24 networks

PC0 and PC1 belong to different IPv4 networks. Router0 connects to both networks directly and acts as each PC's default gateway. Each PC must use an IP address, subnet mask, and gateway that match its local router interface.

Device Address Mask Gateway
Router0 Gi0/0 192.168.1.1 255.255.255.0 —
PC0 192.168.1.100 255.255.255.0 192.168.1.1
Router0 Gi0/1 10.10.10.1 255.255.255.0 —
PC1 10.10.10.100 255.255.255.0 10.10.10.1

Router configuration sequence

Use enable to enter privileged EXEC mode, configure terminal to enter global configuration mode, and interface to select a router port. Apply ip address and no shutdown on both interfaces. Return to privileged EXEC mode with end and save with copy running-config startup-config .

Interface names depend on the router model. The book uses a 2911 with GigabitEthernet0/0 and GigabitEthernet0/1 .

Verifying IP reachability

From PC1's Desktop → Command Prompt, run ping 192.168.1.100 . A successful reply indicates reachability to PC0 through Router0. An initial ping packet may time out while address resolution occurs; repeat the test if necessary.

Saving the .pkt topology is separate from saving the router's running configuration to startup configuration.
