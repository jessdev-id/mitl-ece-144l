SOHO Ethernet LANs

Small office/home office networks typically combine wired Ethernet clients, Wi-Fi clients, and an integrated router with switching and wireless access-point functions. Ethernet defines wired LAN physical and data-link operation; Wi-Fi uses a different wireless LAN standard.

Typical path: Wired PC → integrated switch → router → WAN. Wireless clients reach the LAN through the access point.

Enterprise Ethernet LANs

Enterprise networks use multiple switches and structured cabling to connect end devices throughout a building or campus. Access switches connect endpoints; inter-switch links join portions of the LAN. Ethernet standards define the physical links while a common Ethernet frame format supports communication across different Ethernet media.

LAN: typically nearby devices in a building or campus. WAN: connects sites separated by greater distances.

Twisted-Pair Transmission

UTP uses eight copper conductors organized into four twisted pairs. Twisting helps reduce electromagnetic interference and crosstalk. 10BASE-T and 100BASE-TX use two pairs; 1000BASE-T uses all four pairs and sends in both directions over each pair.

Typical copper Ethernet channel length: up to 100 meters for common twisted-pair links.

Straight-Through vs. Crossover

For traditional 10/100 Ethernet, a straight-through cable maps pin 1→1, 2→2, 3→3, 6→6. A crossover swaps the transmit and receive pairs: 1→3, 2→6, 3→1, 6→2. Modern auto-MDIX-capable interfaces can often adapt automatically.

Traditional examples: PC ↔ switch: straight-through; switch ↔ router: straight-through; PC ↔ PC: crossover.

Fiber-Optic Fundamentals

Fiber carries light instead of electrical signals. A glass core and surrounding cladding guide light along the cable. Fiber resists electromagnetic interference and can support distances beyond common copper Ethernet limits.

Multimode vs. Single-Mode

Multimode fiber (MMF) uses a larger core and supports multiple light paths; it is commonly used for shorter fiber links. Single-mode fiber (SMF) uses a much smaller core and is preferred for long distances. Optical transceivers and fiber types must match the Ethernet standard.

Ethernet Data-Link Header & Trailer

Ethernet frames contain destination and source MAC addresses (6 bytes each), a 2-byte Type field for Ethernet II frames, payload, and a 4-byte frame check sequence (FCS) trailer. EtherType 0x0800 identifies IPv4; 0x86DD identifies IPv6. FCS detects errors; it does not repair damaged frames.

MAC Addresses & Duplex

A MAC address is 48 bits (12 hexadecimal digits). A typical universally administered address begins with a 24-bit organizationally unique identifier (OUI). Unicast targets one interface, broadcast uses FFFF.FFFF.FFFF, and multicast targets a group. Modern switched full-duplex links send and receive simultaneously without collisions; shared hub-based half-duplex Ethernet uses CSMA/CD.

4. Capture and inspect

Open PC-A → Desktop → Command Prompt → ping 192.168.10.20. In Simulation Mode, show ARP and ICMP. Use Capture/Forward and click envelopes to inspect inbound/outbound PDU details. Record source/destination MAC addresses and EtherType. Re-run ping after ARP resolves and compare frames.

5. Expected observations

The switch learns source MAC addresses on ingress ports. Unicast frames addressed to a learned destination are forwarded toward that port. An ARP request uses the Ethernet broadcast destination FFFF.FFFF.FFFF. Ethernet frame FCS is an error-detection mechanism, not a retransmission protocol.
