Course Overview

Course Description

This course is the laboratory component of ECE144 (Data Communication) which provides hands-on experience on data communications and networking. It covers foundational knowledge and skills needed to show how networks operate, including the devices, media, and protocols that enable network communications that validates a student’s skills and knowledge on entry-level networking concepts and topics.

Professional Preparation

Industry-Recognized Certification / Internship / Long-Term Project

At the end of this laboratory course, students will be able to complete Cisco Network Technician professional certificate available at the Cisco Networking Academy, which prepares them for the entry-level Cisco Certified Support Technician (CCST) Network certification. Students will also design a network for a small building campus using Cisco Packet Tracer.
