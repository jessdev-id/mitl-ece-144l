Lecture & Discussion Notes

Learn the tools and terms you will use repeatedly in subsequent laboratory activities.

Know Your Workspace

Logical Workspace: Build and view network topology diagrams. Use this view for the primer.

Physical Workspace: View geographic/building representations; not needed for your first lab.

Device Selection Box: Choose Network Devices (routers/switches), End Devices (PCs/servers), and Connections (cables).

Realtime / Simulation: Realtime runs the network continuously; Simulation lets you step through protocol events.

Device Window: Click a device to access Physical, Config, CLI, Desktop, or Services tabs, depending on device type.

First 5 Minutes

  1. Open Cisco Packet Tracer and create a new file.
  2. Choose the Logical workspace.
  3. Find the Network Devices and End Devices categories.
  4. Drag one PC and one switch into the workspace.
  5. Double-click each device and explore its available tabs.
  6. Save as ECE144L_Lab0_YourSurname.pkt.

Interface labels can vary slightly by Packet Tracer version.

Recognize the Equipment

PC: Generates traffic; use Desktop → IP Configuration and Command Prompt.

Switch (2960): Connects local Ethernet devices; CLI supports basic IOS commands.

Router: Connects different IP networks; used in Lab 1.

Server: Can provide HTTP and other network services.

Connect the Right Ports

Choose Connections (lightning-bolt icon) → Copper Straight-Through. For this exercise, connect PC FastEthernet0 to Switch FastEthernet0/1, then the second PC to FastEthernet0/2.

A green link indicator normally means the interface is operational. Wait for switch ports to transition to forwarding; initial amber lights can be normal.

Tip: Automatic Connection can select a cable for you. Learn manual selection first so you understand ports and media.

Static IPv4 Setup

  1. Click PC0 → Desktop → IP Configuration.
  2. Select Static.
  3. Enter IPv4 address 192.168.10.10.
  4. Enter subnet mask 255.255.255.0.
  5. Configure PC1 with 192.168.10.20 and the same mask.
  6. Leave default gateway blank for this same-subnet, no-router exercise.

What the Settings Mean

IP address: Identifies a host's logical address. Subnet mask: Identifies which address bits belong to the network. Default gateway: Router address used for destinations outside the local subnet.

On PC0, go to Desktop → Command Prompt and run:

ipconfig
ping 192.168.10.20

The first ping may time out while ARP resolution occurs. Repeat if needed.

Realtime vs Simulation

Use Realtime to build and test normally. Switch to Simulation to observe discrete events and protocol behavior.

  1. Click Simulation at the bottom right.
  2. Open Edit Filters and select ARP and ICMP.
  3. Generate a ping from PC0 to PC1.
  4. Use Capture/Forward to advance one event at a time.
  5. Click an envelope to inspect OSI Model and Outbound/Inbound PDU Details.

What to Look For

First, PC0 may broadcast an ARP Request to discover PC1's MAC address. PC1 replies with an ARP Reply. Then PC0 sends an ICMP Echo Request and PC1 responds with an ICMP Echo Reply.

Key observation: A switch forwards Ethernet frames; two hosts on the same subnet do not need a router to exchange packets.

Lab 0.1 Complete Packet Tracer Build Guide

Beginner-friendly setup, addressing, commands, and verification

1. Devices and connections

Place two PCs (PC0, PC1) and one Catalyst 2960 switch (SW1) in the Logical workspace. Use copper straight-through cables: PC0 FastEthernet0 → SW1 FastEthernet0/1; PC1 FastEthernet0 → SW1 FastEthernet0/2.

2. Addressing table

DeviceIPMaskGateway
PC0192.168.10.10255.255.255.0Blank
PC1192.168.10.20255.255.255.0Blank
SW1Not required——

3. Configure the switch CLI

Click SW1 → CLI. Answer no if prompted to enter the initial configuration dialog, then press Enter.

enable
configure terminal
hostname SW1
interface fastEthernet 0/1
 description To-PC0
 no shutdown
exit
interface fastEthernet 0/2
 description To-PC1
 no shutdown
end
show interfaces status
show running-config
copy running-config startup-config

Interface labels depend on the device model. Use the ports actually connected in your topology.

4. Configure and test hosts

For each PC, select Desktop → IP Configuration and enter its static IPv4 settings. On PC0, open Desktop → Command Prompt and type:

ipconfig
ping 192.168.10.20

If ping fails, inspect cabling, port LEDs, addressing, subnet masks, and interface status. Try again after ARP has completed.

5. Inspect Simulation Mode

Switch to Simulation, filter for ARP and ICMP, ping PC1 again, then advance using Capture/Forward. Click the envelopes and observe ARP Request/Reply and ICMP Echo Request/Reply. If ARP is already cached, clear the relevant ARP entry or restart the scenario before capturing.

6. Save and submit

Save ECE144L_Lab0_YourSurname.pkt. Suggested evidence: topology screenshot, both PC IPv4 settings, successful ping, and one PDU inspection screenshot. Follow your instructor's submission instructions.
