Learning Source MAC Addresses

When a frame enters a switch, it records the source MAC address and the receiving port in its MAC address table. Dynamic entries can age out after inactivity; the textbook notes that a typical default aging interval is 300 seconds . 

Switch# show mac address-table

This command displays learned MAC addresses, VLANs, entry types, and associated ports.

Where Does a Frame Go?

Known Destination

The switch looks up the destination MAC address and forwards a unicast frame through its associated port, avoiding unnecessary copies.

Unknown or Broadcast Destination

The switch floods the frame through other ports in the same VLAN, excluding the incoming port . The Ethernet broadcast address is ffff.ffff.ffff .

Three Switching Methods

Store-and-forward

Receives the complete frame and checks its FCS before forwarding.

Cut-through

Begins forwarding after reading enough of the frame to identify the destination MAC address.

Fragment-free

Waits for the first 64 bytes before forwarding, to catch certain early-frame errors.

Ethernet Frame Format

Field Size Purpose
Preamble 7 bytes Receiver synchronization
Start Frame Delimiter 1 byte Marks the start of frame fields
Destination MAC 6 bytes Intended recipient
Source MAC 6 bytes Sender; used for MAC learning
Length/Type 2 bytes Identifies carried protocol
Data and Pad 46–1500 bytes Payload and minimum-size padding
FCS 4 bytes Detects transmission errors

The textbook identifies 1500 bytes as the default Ethernet data MTU; frame overhead is separate.
